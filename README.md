# La nuit des revenants

Enquête-quiz d'Halloween sur les légendes du Québec, pour le TBI et un carnet d'enquête par équipe.

**Page publique : https://merciermathieu5.github.io/nuit-des-revenants/**

## Contenu

- `index.html` : la page d'accueil à partager avec les collègues.
- `activite.html` : l'activité, en un seul fichier qui fonctionne aussi hors ligne (Chrome ou Edge). Le bouton Documents, en bas de l'écran, donne accès aux trois PDF en tout temps.
- `carnet-enquete.pdf` : le carnet d'enquête, recto verso, un par équipe.
- `fiches-historiques.pdf` : les six fiches historiques, un jeu par équipe.
- `guide-animateur.pdf` : le guide d'une page pour l'animateur.

## Crédits

Activité imaginée par Mathieu Mercier, École secondaire de Rivière-du-Loup. Interface et documents produits à l'aide de l'intelligence artificielle Claude Opus 5.5 (Anthropic).
